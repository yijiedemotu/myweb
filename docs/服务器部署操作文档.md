# 部署 / 上传到服务器操作文档

本网站（个人作品 + 博客 + SQLite + Next.js）上传到你自己的服务器并稳定运行的**详细操作说明**。以 **Ubuntu/Debian + Nginx + pm2** 为例。

> 对应“面向国内访客”时需注意 ICP 备案（见 §8）。

## §1 准备服务器

| 项 | 建议 |
| --- | --- |
| 系统 | Ubuntu 22.04 / Debian 12（或你熟悉的其他 Linux） |
| 配置 | 2C4G 起足够（本机 Node 即可，无需额外数据库服务） |
| 网络 | 有公网 IP；面向国内可选大陆机房，面向全球可选海外 |
| 端口 | 放行 80、443、22（SSH） |

SSH 登录示例：

```bash
ssh root@你的服务器IP
# 或使用你的用户名： ssh 用户名@IP
```

## §2 安装运行环境

以 root（或 sudo 用户）执行：

```bash
# 1) 更新系统
apt update && apt upgrade -y

# 2) 安装 Node.js 20 LTS 及以上（推荐用 NodeSource 官方源）
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs git

# 验证
node -v   # v20.x 或更高
npm -v

# 3) 安装进程守护 pm2
npm install -g pm2

# 4) 安装 Nginx（后面做反向代理用）
apt install -y nginx
```

> 若安装 better-sqlite3 需要**本地编译**（拿不到预编译时），还要装编译工具：
> `apt install -y build-essential python3 make`

## §3 把代码上传到服务器（选一种）

### 方式 A：git 克隆（推荐）
先在 GitHub 建好私有/公有仓库并推送代码，然后在服务器拉取：

```bash
cd /srv
git clone <你的仓库地址> portfolio
cd portfolio
```

首次推送前在本地确认已把 `data/site.db*` 忽略（在 `.gitignore` 里），`data/seed/` 正常提交。

### 方式 B：scp / 压缩包上传
在你**本地**项目目录里：

```bash
# 本地打包（排除 node_modules / .next / data 运行时库）
tar --exclude=node_modules --exclude=.next --exclude='data/site.db*' -czf portfolio.tar.gz .
scp portfolio.tar.gz root@你的服务器IP:/srv/
```

在服务器解压：

```bash
cd /srv && mkdir -p portfolio && tar -xzf portfolio.tar.gz -C portfolio && cd portfolio
```

### 方式 C：SFTP / FileZilla
用 FileZilla 等连上服务器后，把项目文件拖到 `/srv/portfolio`（同样排除 node_modules/.next）。

## §4 安装依赖并构建

在项目目录 `/srv/portfolio` 执行：

```bash
npm ci          # 按 package-lock 精确安装
npm run build   # 生产构建
```

> 如果安装 better-sqlite3 报错 / 网络慢，可改用国内 npm 镜像：
> ```bash
> npm config set registry https://registry.npmmirror.com
> ```

## §5 配置环境变量

```bash
# 生成随机后台密码
openssl rand -hex 24
```

在 `/srv/portfolio` 创建 `.env.local`：

```bash
cat > .env.local <<'EOF'
ADMIN_PASSWORD=<上面生成的随机密码>
NEXT_PUBLIC_SITE_URL=https://你的域名   # RSS/绝对链接用；没域名可先不填
EOF
```

> `ADMIN_PASSWORD` 就是网站后台 `/admin` 的登录密码（**务必修改**，默认是 changeme）。

## §6 用 pm2 常驻运行

```bash
# 在项目目录执行（注意参数用两个减号分隔）
pm2 start "npm run start" --name portfolio -- -p 3000
pm2 save                 # 保存当前进程列表
pm2 startup              # 生成开机自启命令，按提示复制执行一次
```

常用管理命令：

```bash
pm2 status               # 查看状态
pm2 logs portfolio       # 查看实时日志
pm2 restart portfolio    # 重启
pm2 stop portfolio       # 停止
```

**目录权限**：程序要向 `data/` 写 SQLite（`data/site.db*`），确保运行用户对该目录可写：

```bash
chown -R 运行用户:运行用户 /srv/portfolio/data
```

## §7 Nginx 反向代理 + HTTPS

在项目目录外新建站点配置：

```bash
nano /etc/nginx/sites-available/portfolio
```

内容：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

启用并重载：

```bash
ln -s /etc/nginx/sites-available/portfolio /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx
```

**HTTPS（推荐）**，用 certbot 自动申请并改写配置：

```bash
apt install -y certbot python3-certbot-nginx
certbot --nginx -d your-domain.com
```

> 申请前请先让域名解析到服务器 IP。开启 HTTPS 后，后台 cookie 会自动带 `Secure`。

## §8 备案提醒（国内服务器）

只要内容托管在**大陆机房**且用域名对外提供 80/443 服务，就**必须 ICP 备案**。备案在你云厂商控制台在线办理（个人备案即可），审核通常 7–20 天。若不想备案，可用海外服务器或 Cloudflare Pages 等。

## §9 数据备份 / 更新发布 / 常见问题

### 备份（核心是数据库）
```bash
# 停止写入更稳妥（可选：直接复制也行）
cp /srv/portfolio/data/site.db /srv/backup/site-$(date +%F).db
# 或用 sqlite 命令
sqlite3 /srv/portfolio/data/site.db ".backup /srv/backup/site-$(date +%F).db"
```
建议用 cron 每天备份，并定期拷到本地/对象存储。

### 更新发布
```bash
cd /srv/portfolio
git pull          # 或重新上传代码
npm ci
npm run build
pm2 restart portfolio
```

### 常见问题排查
| 现象 | 处理 |
| --- | --- |
| `pm2 status` 显示 error / 端口占用 | `pm2 logs portfolio` 看日志；`EADDRINUSE` 说明 3000 被占，换端口或杀掉旧进程 |
| better-sqlite3 编译失败 | 安装 `build-essential python3 make` 后重新 `npm ci`，或换国内镜像 |
| 页面能开但“后台 /admin”进不去 | 确认 `.env.local` 里 `ADMIN_PASSWORD` 正确；重启 pm2 生效 |
| 打开是空白 / 502 | `nginx -t`；检查是否 `pm2 start`、proxy_pass 端口是否一致 |
| 改了什么不生效 | 需要重新 `npm run build`（Next 是编译产物）再 `pm2 restart` |
